PRIVACY POLICY

Wave Planner & its Discord bot  ·  Last updated 10 August 2026

Wave Planner is a hobby tool for coordinating a single kingdom in the online game Utopia. It has no commercial purpose, no advertising and no user accounts. This page describes what the tool and its Discord bot store, where that data lives, and how to have it removed.

What the Discord bot reads

The bot is invited to one Discord server and reads one channel, the one carrying the game's automated DRAGON event messages. From that channel it keeps only the lines matching that format, for example:

  • DRAGON Ankylosaurus Rex [bridg#] donated 62,093 gold coins to fund dragon!
  • DRAGON Dilophosaurus [borwhack] sent 350 troops and weakened dragon by 3723 points!

For each such line it stores the Discord message ID and timestamp, plus the values parsed out of it: the in-game province name, the in-game ruler name, the type of contribution, and the amount.

What it does not read or store

  • Discord usernames, user IDs, display names or avatars
  • Direct messages, and messages in any channel other than the configured one
  • Messages that do not match the DRAGON event format — these are discarded, not stored
  • Attachments, images, voice, or presence information

The names it does keep are in-game identifiers chosen by players for a game world, not real names or contact details.

What the planner itself stores

Separately from the bot, the Wave Planner browser tool stores game data for the kingdom using it: province statistics pulled from the official Utopia Intel Site, war plans written by the kingdom's leader, notes, and the dragon contribution totals described above. This is game information about provinces, not personal information about people. One optional field, a player's Discord handle, may be entered by the kingdom's leader so orders can be addressed to the right person.

Why

To rank which provinces have contributed to a dragon, and to remind those who have not yet taken part. That is the whole purpose.

Where the data lives

  • Google Cloud Run and its attached storage, region europe-west1 (Belgium) — raw ingested events
  • Google Cloud Firestore, project utopia-leaderboard — the aggregated data the tool reads

Both are operated by Google Cloud on the operator's behalf. Nothing is sent anywhere else.

How long it is kept

Event storage is capped and rolls over, keeping only the most recent records. Game data is cleared between Utopia ages, which happens every few months. Anything may be deleted sooner on request.

Sharing

Nothing is sold, rented, or shared with third parties. The data is visible to members of the kingdom running the tool, which is the point of it. No analytics or tracking services are embedded in the tool or this site.

Removing your data

Ask, and it will be deleted. Contact details are below. Because the stored records are keyed by in-game province name, please say which province you mean. Removing the bot from the server stops all collection immediately.

Children

The tool is not directed at children and stores no information that would identify a person's age. Discord requires its users to be at least 13, or older where local law says so.

Changes

If this policy changes, the date at the top changes with it. There is no mailing list to notify; the current version is always the one on this page.
